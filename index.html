Parsing OBD-II & GPS coordinates in real-time.

Motorcycling isn't just sensory—it is rich sensor telemetry. This Java record structure parses raw CAN-bus payloads into lean telemetry metrics for route performance audits.

Java 21 CAN-Bus Telemetry
TelemetryFrame.java 
package in.codeandthrottle.telemetry;

import java.time.Instant;

/**
 * Immutable flight-recorder snapshot for motorcycle dynamics.
 */
public record TelemetryFrame(
    Instant timestamp,
    int rpm,
    double speedKmh,
    int gear,
    double leanAngle,
    double throttlePosition
) {
    public boolean isNearRedline() {
        return rpm >= 9200;
    }

    public boolean isHighCommitmentCorner() {
        return Math.abs(leanAngle) > 42.0 && speedKmh > 65.0;
    }
}
